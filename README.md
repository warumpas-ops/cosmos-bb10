# 🌙 Cosmos (BlackBerry 10)

> A smart retro-cosmic alarm clock crafted for BlackBerry 10 with Alarmy-inspired wake-up missions, Space Grotesk typography, and a real-time pixel moon with craters and twinkling stars.

---

### ✨ Features
- **Celestial Pixel Art Moon**: Custom canvas-rendered pixel moon with craters, rims, gentle floating bobbing, and sparkling cross stars.
- **Alarmy-Style Wake-Up Missions**:
  - **Math Challenge**: Solve arithmetic problems (Easy, Medium, Hard) to dismiss the alarm.
  - **Shake Challenge**: Physical accelerometer-based shake counting.
  - **Typing Challenge**: Type inspiring quotes to activate your brain.
  - **Normal Alarm**: Quick 1-tap dismiss.
- **Space Grotesk Monospaced Typography**: Dark cosmic monochrome theme (`#0F0F10`, `#171719`, `#252528`, `#F2F2F2`).
- **Upcoming Alarm Hero**: Live countdown display (*"NEXT ALARM IN X HOURS Y MINS"*).
- **BlackBerry 10 Native**:
  - Ultra-lightweight ~88 KB APK.
  - Pure Android API 18 / Holo base (zero AndroidX dependencies).
  - Perfectly proportioned for 720×720 square displays (Passport, Classic, Q10).
  - Physical QWERTY keyboard support with instant Enter key submission.

---

### 📲 Installation
1. Download `Cosmos.apk` from the [Releases](https://github.com/warumpas-ops/cosmos-bb10/releases) tab.
2. Transfer the APK to your BlackBerry 10 device or microSD card.
3. Open the file in the BlackBerry File Manager and tap **Install**.
