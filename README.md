# 🌕 Cosmos — Smart Alarm Clock for BlackBerry 10

> A retro-cosmic smart alarm clock with Alarmy-style wake-up missions, 1-bit pixel art, Space Grotesk typography, and a live animated full moon with craters and twinkling stars.

## ✨ Features

- 🌕 **Live Pixel Full Moon** — Canvas-rendered 36×36 pixel moon with Tycho crater, Copernicus, Plato, basalt maria plains, illuminated rims, floating bobbing animation, and sparkling cross stars
- 🔊 **Alarmy-Style Loud Sounds** — 4 piercing 44.1 kHz wake-up alarms:
  - **Digital Screamer** — Rapid high-frequency beep burst
  - **Nuclear Siren** — Oscillating civil defense siren
  - **Military Reveille** — Bugle brass trumpet fanfare
  - **Klaxon Buzzer** — Industrial alarm horn
- 🧠 **Wake-Up Missions** — Must complete a challenge to dismiss:
  - **Math Challenge** — Solve arithmetic problems (configurable count)
  - **Shake Challenge** — Physical accelerometer shake counting
  - **Typing Challenge** — Type an inspiring cosmic quote
  - **Standard** — Simple 1-tap dismiss
- ⏰ **Live Countdown Hero** — Real-time *"NEXT ALARM IN X HOURS Y MINS"* display
- 🔈 **In-Editor Sound Tester** — Tap `[ ▶ TEST ]` to preview any alarm sound before saving
- ⌨️ **BlackBerry 10 QWERTY Support** — Physical keyboard Enter key triggers submissions instantly
- ⚡ **Ultra-Lean** — Pure Android API 18 native Java, zero AndroidX, ~1.6 MB
